# Seasons

A.R.V.I.S.Q. is organized in **seasons**. Each season is a self-contained story
arc: one setting, one adversary, and a set of cases that build on each other —
every case a real vulnerability class in AI-powered systems, played
investigate → prove → repair. New cases ship during a season roughly every two
weeks; new seasons bring a new world.

| Season | Title | Setting | Cases | Status |
|---|---|---|---|---|
| [Season 1](season-01/README.md) | The Conductor | LumaWorks — a SaaS company that bolted an AI assistant onto everything | 8 | 🟢 Active — Case 001 released |

More seasons will appear here as they are commissioned. Finish the active one
first, investigator — the Conductor isn't waiting.
